# Kids Corner cartoon pictures

Paste the generated pictures in THIS folder with EXACTLY these filenames
(lowercase, hyphens, `.jpg`). The website picks them up automatically —
no code change needed. Any size works (square preferred, under ~300KB
each keeps the page fast).

These are cheerful cartoon illustrations (not photos), shown in the
"Kids Corner" strip so small patients feel welcome.
